# Mahin Kuhenuri - Terapias Naturales & Enfermería

## Project Overview
Professional website for Mahin Kuhenuri, a Swiss-qualified nurse and naturopath with 35+ years experience, operating a natural therapies and nursing practice in La Barceloneta, Barcelona.

## Technical Stack
- Single-page public site with hash navigation (#inicio, #sobre-mi, #servicios, #galeria, #contacto)
- Admin CMS at /admin (login at /admin/login) for visual content editing
- PostgreSQL database (Prisma ORM) for services, gallery, contacts, users
- NextAuth v4 with JWT strategy for admin authentication
- S3 cloud storage configured for file uploads
- Email notifications via Abacus API for contact form submissions (to mahineta@hotmail.com)

## Visual Style
- **Primary**: Olive green HSL(82, 35%, 35%) → #6B7B3A
- **Background**: Warm beige HSL(40, 30%, 96%) → #F5F0E8
- **Tone**: Warm, human, emotional, professional
- **Fonts**: DM Sans (body), Plus Jakarta Sans (display), JetBrains Mono (mono)
- **Design references**: sandravaldivia.es, pepisychema.com

## Key Features
- **Multi-language**: ES / CA / DE / EN via React context-based i18n
- **WhatsApp integration**: Floating button (bottom-right) + per-service WhatsApp buttons
- **Contact form**: Saves to DB + email notification to mahineta@hotmail.com
- **CMS/Backoffice**: Admin panel to edit services (4 languages), gallery, view messages
- **Services**: 21 services in 4 categories (western, oriental, programs, nursing)
- **Pricing**: 1€/min with senior discount (-10€)

## Data Model
- User (admin auth)
- Service (slug, category, multilingual names/descriptions, image)
- GalleryImage (url, multilingual captions, sort order)
- ContactSubmission (name, email, phone, subject, message, lang, status)
- SiteContent (key-value CMS for dynamic text blocks)

## Page Structure (Multi-page with route groups)
- `/(public)/` - Home page (Hero + Stats + Service highlights + About preview + CTA)
- `/(public)/sobre-mi` - About page (Bio, credentials, philosophy, values)
- `/(public)/servicios` - Services page (Category tabs: western/oriental/programs/nursing)
- `/(public)/tarifas` - Pricing page (Rate cards, inclusions, CTA)
- `/(public)/galeria` - Gallery page (Grid with lightbox)
- `/(public)/contacto` - Contact page (Form, map, contact info)
- `/admin/login` - Admin login page
- `/admin` - CMS dashboard (Services editor, Messages inbox, Gallery manager)
- Public layout at `(public)/layout.tsx` wraps all public pages with LangProvider, Header, Footer, WhatsAppFloat
- Navigation uses Next.js Link component with pathname-based active states
- `/(public)/politica-privacidad` - Privacy Policy (RGPD compliant, 4 languages)
- `/(public)/politica-cookies` - Cookie Policy (4 languages)
- `/(public)/aviso-legal` - Legal Notice / Impressum (4 languages)
